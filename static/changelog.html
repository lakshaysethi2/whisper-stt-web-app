Changelog

Dated changes deployed to audio.lak.nz. Newest first.

2026-08-08
  • Parakeet TDT 0.6B v3 — added as a selectable model (parakeet-tdt-0.6b-v3 → nvidia/parakeet-tdt-0.6b-v3). FastConformer-TDT, 25 EU languages auto-detect, punctuation/casing, word+segment timestamps. Runs via transformers (shares torch stack with CrisperWhisper); optional at boot — shows "Parakeet unavailable" when not installed.
  • GPU Node B — librosa fix — worker image was missing librosa + soundfile required by Parakeet (and CrisperWhisper container decode). Parakeet jobs on Node B failed until the deps were added. Fixed.
  • CrisperWhisper CPU fallback on Maxwell/Pascal — torch CUDA 13 ships no sm_50 kernels; CrisperWhisper now falls back to CPU on those GPUs instead of crashing.
2026-08-07
  • GPU worker dispatch — transcription can be dispatched to laptop GPU workers (config via config/nodes.yaml, round-robin). Frontend Transcription node picker: Automatic / GPU Node A / GPU Node B / CPU, with live online/offline status and neutral labels. Explicit node choice is exclusive — failure fails the job with a named-node error, never a silent switch.
  • No main-host CPU transcription by default — WHISPER_ALLOW_LOCAL_CPU=false (default) — undispatchable jobs fail cleanly ("No transcription node available") instead of running on the VPS CPU (a prior CPU job OOM-crashed the host).
  • Worker image (Dockerfile.worker) — CTranslate2 v4.8.1 built from source for sm_50/sm_61 (pip wheel only ships sm_86/90/100), with reverse-tunnel networking (10.99.0.1 + host.docker.internal).
  • Reliability — completed/failed jobs keep stage=done + live node so results show which node ran the job; MIN_FREE_DISK_BYTES default lowered to 512 MB so the 2 GB tmpfs work dir no longer rejects every upload.
2026-08-03
  • CrisperWhisper 2.0 (verbatim ASR) — optional models crisperwhisper-large/turbo/medium/small (HF: nyralabs/CrisperWhisper2.0_*). Verbatim vs intended mode per job, word-level timestamps, single-thread executor, ffmpeg pre-decode for container audio (e.g. MP4). Backend auto-resolves to transformers on this stack (ct2 extra conflicts with faster-whisper and has no ARM64 wheels).
  • Split retention — transcripts kept 1 week (JOB_RETENTION_SECONDS=604800, ≥1h required), recordings deleted sooner (30 min) and immediately on completion; status endpoint now returns retention_seconds/expires_at/expires_in_seconds. Interrupted jobs restored as "interrupted" after restart (never 404) with re-upload guidance.
2026-08-01
  • Mandatory model choice — no silent default; users must pick a model before transcribing (400 if missing). Save-link with copyable /j/{job_id}, resume views for interrupted/expired jobs, and browser-STT links.
2026-06-22
  • Chunked upload — bypasses Cloudflare 100 MB limit (5 MB chunks, finish returns job_id immediately, poll /api/transcribe/status/{job_id}). Also: job IDs are full 32-char uuid4 hex; jobs persisted to WORK_DIR/<id>/status.json for resume.
